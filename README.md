# GitHub Pages site for Cynthia Marie Paderes

This repository contains a simple static portfolio/CV website built for GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or run a local static server from the repo root:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages deployment

1. Push this repository to GitHub.
2. Go to repository Settings > Pages.
3. Set the source to the default branch (`main`) and folder `/` (root).
4. Save the settings and wait for the site to publish.
5. The site will be available at:

```text
https://cynthiamariedorado.github.io/cynthia-marie-paderes-cv/
```

## Notes

The content is based on the CV details provided and includes the most relevant professional experience, competencies, and contact information. You can update the text later in `index.html` as needed.
